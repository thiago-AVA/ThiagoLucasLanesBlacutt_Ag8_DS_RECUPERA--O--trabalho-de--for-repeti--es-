# Pesquisa de Satisfação

## sobre
O programa coleta informações dos entrevistados e registra suas opiniões, permitindo visualizar os resultados ao final da pesquisa.

## Objetivos
- Coletar o nome e a idade dos entrevistados.
- Registrar a opinião dos clientes sobre o atendimento.
- Utilizar a estrutura de repetição `for`.
- Aplicar estruturas de decisão `if`, `elif` e `else`.
- Contabilizar as respostas recebidas.
- Exibir um relatório final com os resultados.

## Tecnologias utilizadas

- Python 3
- VS code
- GitHub

## Obs, para mudar a quantia de 10 para 50 avaliações, é so mexer na variavel "TOTAL_ENTREVISTADOS".
